# Casing Core For Claude Code

This project is wrapping (aka. `Casing`) `claude code` to better control setup across team members. This is done by delivering a unified image that can (also) be easily configured.

| [🔗](https://github.com/open-llm-space/Casing/blob/main/claude%20code/core/README.md) | `core` | Contains the base solution. A local `docker`-based solution |
| :--: | :--- | :--- |

| [🔗](https://github.com/open-llm-space/Casing/blob/main/claude%20code/extensions/base/README.md) | `extensions/base` | A template for extending `core` image with custom additions and updates |
| :--: | :--- | :--- |

| [🔗](https://github.com/open-llm-space/Casing/blob/main/claude%20code/extensions/graphify/README.md) | `extensions/graphify` | A real-life extension example of using the `graphify` project to reduce `claude code` tokens usage |
