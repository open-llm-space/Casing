# Casing Core For Claude Code

This project is wrapping (aka. `Casing`) `claude code` to better control setup across team members. This is done by delivering a unified image that can (also) be easily configured.

| | |
| :--- | :--- |
| `core` | Contains the base solution. A local `docker`-based solution |
| `extensions/base` | A template for extending `core` image with custom additions and updates |
| `extensions/graphify` | A real-life extension example of using the `graphify` project to reduce `claude code` tokens usage |
